# EcoBots
![EcoBots ico](media/wallpaper.png)

[EcoBots UML](UML_EcoBots.pdf)

## Description:
The code for a Survival/Life Simulation Game made for my Rainbow Academy thesis in one month.

## Features:
All customizable:

Menu System
-Locomotion System
-Character Personalization System
-Video and Sound Personalization System
-Quest System
-Money System
-Stats System
-HUD System
-Villagers System
-Inventory System
-Interaction System
-Build System
-Gathering Resources System
-Save Data System
-Day/Night System
-Catastrophes / World Condition System
-Procedural Level Generation
  
## How to Use:
1. Create a Unreal Engine project
2. Setup in Engine to build Your game
